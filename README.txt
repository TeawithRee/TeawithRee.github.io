# Tea with Ree: six-image repair package

This is a small content-only repair package for six pages that are already live but currently request missing image assets. It does not replace article pages.

## Upload

Upload the six files inside `images/` into the repository root `images/` folder. Replace `sitemap.xml` with the included sitemap. Do not upload the whole site and do not replace `index.html`, `style.css` or `CNAME`.

- pexels-eco-tips-recycling.webp

The live sitemap already contains the Eco-Tips URL. The included sitemap adds the other five missing article URLs while preserving the current live URLs.

After deployment, check the six image URLs publicly and then check all 13 article pages again.
