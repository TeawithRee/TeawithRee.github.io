# Tea with Ree: seven-article content-only staging package

This package was prepared and visually checked by Manus. It has not been uploaded to GitHub. It contains two Modern Tools articles, two Books articles, two Inner Work articles and one Wellbeing article.

## Files to add or replace

- Add all seven files in `articles/` to the repository root using their filenames without the `articles/` folder.
- Add all seven files in `images/` to the repository root using their filenames without the `images/` folder.
- Replace only the four files in `sections/`: `tools.html`, `books.html`, `inner-work.html` and `wellbeing.html`.
- Update the sitemap with the seven new URLs. Do not replace `index.html`, `style.css` or `CNAME`.

## Homepage

The homepage and Latest Stories remain unchanged in this package. Do not add all seven to the homepage. If one is later selected for Latest Stories, prepare that as a separate explicit homepage change.
