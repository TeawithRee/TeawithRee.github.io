# Tea with Ree: alt text for the remaining 64 pictures

Prepared 23 September 2026. This replaces every remaining `alt="Visual companion to ..."` on the site (151 instances across 79 pages, 64 unique pictures).

## The rule, for these and for every picture added from now on

Alt text must carry the feeling the article gives the photo, not a list of what is in the frame. It still has to name what the picture is, because someone using a screen reader cannot see it. One sentence. No "Visual companion to", no article titles, no "image of", no "photo of".

Right: *Eyes of hope behind the kennel gate, freedom on the other side.*

Wrong: *A white dog behind a rusted kennel gate.*

## How to apply it

For each picture below, set the `alt` attribute to the given sentence everywhere that picture appears: the article page, the section page card, and the 480w / 900w / 720w versions of the same file. Where the picture also appears in `stories.json` or in `og:image` / `twitter:image` descriptions, use the same sentence. Change nothing else: no image files, no captions, no layout.
